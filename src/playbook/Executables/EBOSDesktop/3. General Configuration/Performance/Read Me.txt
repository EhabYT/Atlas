=========================
Performance
=========================

This folder contains optional performance-related features and
helpers for EBOS.

Nothing in this folder is applied by default - every script here
is optional and can be toggled depending on your setup and
preferences. They cover graphics (GPU scheduling, Auto HDR, Game
Mode, Variable Refresh Rate, optimizations for windowed games),
power plans, storage optimization and network helpers.

If you experience an issue after using one of these scripts, run
the corresponding 'Disable' or 'Restore' script, or see the EBOS
documentation: https://docs.ebos.net
